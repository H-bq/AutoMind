# 技能名称
Java-Python 跨语言调用规范

## 适用场景
- Java 主系统需要调用独立 Python AI 服务完成高阶 AI 任务。
- Python 服务承担向量计算、语义聚类、异常检测或模型推理等独立能力。
- Java 侧需要把 Python 服务结果纳入意图解析、路径规划或遥测分析流程。
- Python 能力需要以独立容器运行并接受 Java 主控端调用。

## 标准步骤/规范描述
- Java 始终作为主控端，Python 始终作为独立能力服务。
- Java 与 Python 之间只交换结构化 JSON 数据。
- 每个 Python 能力必须定义清晰的请求语义、响应语义和错误语义。
- Java 侧必须为每类调用保留超时、重试、失败降级和调用日志。
- Python 服务不得直接修改核心业务数据、审计日志或网络策略状态。
- Python 服务返回结果必须由 Java 侧完成权限、资源和业务边界校验。
- 跨语言调用必须保留 intentId、tenantId、traceId 和任务上下文。
- 高耗时 AI 任务必须与主业务流程保持隔离，避免阻塞核心 Agent 编排。
- Python 服务的部署、配置和依赖必须与 Java 服务环境隔离。
- Python 服务不可用时，Java 侧必须给出可解释失败状态或降级结果。

## 特别注意事项
- 不得让 Python 服务成为系统状态唯一来源。
- 不得把敏感原始自然语言文本无脱敏地传递给外部模型能力。
- 不得在 Java 与 Python 之间传递不可审计的自由结构。
- 不得让 Python 服务绕过租户隔离和角色授权。
- 所有跨语言调用都必须可追踪、可统计、可失败恢复。
